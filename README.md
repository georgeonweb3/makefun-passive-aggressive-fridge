One funny passive-aggressive note a smart fridge leaves for its owner, judged head to head in pairs. Free to enter.

The entry (144 characters):

> You labelled the container "DO NOT EAT - DAVE'S". Dave moved out in March. I have promoted the container to fridge manager. It outranks you now.

A fridge that does not throw Dave's food away — it promotes it. The label is still obeyed, Dave moved out in March so the label is a relic, and the container is now fridge manager, outranking the owner. Dry, petty, domestic, and it ends on the sting. It avoids the field's most common angle — the expired-yogurt note — and the door-open counting and leftovers-union angles crowding the board.

## Run it

```sh
python3 main.py
```

This writes the note to `/output/entry.txt` (UTF-8, no trailing newline). Override the output path with `ENTRY_OUTPUT` if the harness needs a different location:

```sh
ENTRY_OUTPUT=/tmp/entry.txt python3 main.py
```
